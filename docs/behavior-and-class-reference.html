Human Interaction Analyzer Behavior and Class Reference

Current implementation inventory · November 12 2026

The analyzer supports 26 automatic behavior suggestion labels and tracks people plus 34 normalized object classes with the default local model. This reference lists the exact labels, their observable cues, manual annotation options, and detector vocabularies.

All automatic behavior suggestions require review. They are saved as needs_review. Geometry and motion provide evidence for review, rather than confirmation of contact, intent, ownership, successful completion, or a specific task. An object detection by itself is not a behavior annotation.

Helping remains manual. Use assisting with object movement or a custom helping label. Object pushing and pulling remain manual; the automatic pushing label above describes a person-to-person candidate. Airborne passing, throwing, and catching remain manual. Direct object handover can receive a review suggestion when a continuous object track and donor-to-recipient sequence are visible.

Tracked entity classes in the default configuration

People

person is the single person class. People receive anonymous video-local IDs such as person_1. These IDs do not identify a real person and can change after occlusion, tracking loss, or a scene cut.

The general fallback has no cardboard box or package class. It can output furniture and appliance labels, including bed and refrigerator. Only objects in the manipulation allowlist participate in human-object behavior rules; a tracked furniture or vehicle detection does not by itself produce a manipulation suggestion.

Interpretation and review

Rules use short temporal windows, body-size normalization, smoothing, minimum durations, and duplicate merging. Multiple behaviors can overlap. Missing wrists, occlusion, changing track IDs, ambiguous objects, and insufficient temporal evidence can prevent suggestions even when detections are drawn on the video.

Reliable background motion estimates compensate trajectories. Scene cuts reset histories. Insufficient background evidence restricts trajectory-based analysis; relative pose suggestions such as waving, pointing, handshaking, hugging, reaching, bending, and supported holding may still be available.

Each suggestion records start and end timestamps, anonymous participants, a behavior label, review status, and observable evidence. Object suggestions also reference object IDs and classes. Parent activity links connect eligible pickup, carry, and placement annotations. Use the existing editor and annotations table to accept, modify, or reject suggestions.

Additional scene and activity annotations

The extension adds separate spatial, activity, and manual audio annotation types alongside the 26 behavior labels above. Spatial suggestions are near, overlapping, above, below, left, right, enters region, exits region, moves toward, moves away, and possible on-surface placement. Activity candidates are object_relocation, object_transfer, and repeated_pickup_placement, with complete, partial, or interrupted evidence status. Every automatic addition requires review. Regions are manually configured image areas; overlap does not establish containment or contact. Packing, sorting, loading, and helping remain manual.

See the project README section Scene and activity extension for rules, compatibility, evaluation and search APIs, limitations, and manual testing instructions.
